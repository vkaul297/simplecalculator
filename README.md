# ⚡ PokéCalc - Gotta Calculate 'Em All! ⚡

A Pokemon-themed calculator available in both Python CLI and HTML formats. Battle numbers with your favorite Pokemon!

## 🎮 Two Versions Available

### 1. Python CLI Version (calculator.py)
Command-line calculator with Pokemon-themed interface and battle log system!

### 2. HTML Web Version (pokecalc.html)
Beautiful, interactive web calculator that runs entirely in your browser - **no server needed!**
Just open the HTML file in any web browser and start calculating!

## ✨ Features

### Pokemon-Themed Math Moves
- ⚡ **Thunder Shock** (Addition) - Pikachu
- 🔥 **Ember** (Subtraction) - Charmander
- 🧠 **Psychic** (Multiplication) - Mewtwo
- 💧 **Water Gun** (Division) - Squirtle
- 🔥 **Fire Blast** (Power) - Charizard
- ⭐ **Swift** (Square Root) - Eevee

### Battle Log System
- 📖 **Trainer Journal** - Automatically tracks all your math battles!
- View your complete calculation history
- 🏥 **Pokémon Center** - Clear your battle log with Nurse Joy's help
- Persists during your training session

### Error Handling
- Division by zero protection: "It's super ineffective!"
- Negative square root: "Eevee fainted!"
- Fun Pokemon-themed error messages

## 🚀 Usage

### Running the Python Calculator
```bash
python3 calculator.py
```

### Python Menu
```
==================================================
⚡ POKÉCALC - CHOOSE YOUR MATH MOVE! ⚡
==================================================
1. ⚡ Thunder Shock (Add) - Pikachu
2. 🔥 Ember (Subtract) - Charmander
3. 🧠 Psychic (Multiply) - Mewtwo
4. 💧 Water Gun (Divide) - Squirtle
5. 🔥 Fire Blast (Power) - Charizard
6. ⭐ Swift (Square Root) - Eevee
7. 📖 Trainer Journal (View Battle Log)
8. 🏥 Pokémon Center (Clear Battle Log)
0. 🚪 Return to Pallet Town (Exit)
==================================================
```

### Running the HTML Calculator
Simply double-click `pokecalc.html` or open it in any web browser!

**Features:**
- Beautiful Pokemon-themed gradient design
- Interactive buttons with hover effects
- Real-time battle log display
- Keyboard support (numbers, operators, Enter, Escape)
- Fully responsive design
- No installation or server required!

### Running Tests
```bash
python3 test_calculator.py
```

### HTML Calculator

- Click buttons or use your keyboard
- See live Pokemon messages for each operation
- Track all calculations in the Trainer Journal
- Beautiful animated effects on errors

## 🎨 HTML Calculator Features

- **No Server Required**: Pure HTML, CSS, and JavaScript
- **Keyboard Support**:
  - Numbers and operators work directly
  - Enter or = to calculate
  - Escape or 'c' to clear
- **Visual Feedback**: Animated buttons and error messages
- **Battle Log**: Keeps last 20 calculations
- **Responsive Design**: Works on desktop, tablet, and mobile

## 📋 Requirements

### Python Version
- Python 3.6 or higher
- No external dependencies required

### HTML Version
- Any modern web browser (Chrome, Firefox, Safari, Edge)
- No installation needed!
